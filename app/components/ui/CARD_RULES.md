# Card Content Rules

Use this guide to keep text-heavy cards consistent and professional.

## 1) Text Roles (Type Tokens)

Assign each text element in a card to one role.

- Eyebrow: 11-12px, uppercase, wider letter spacing
- Title: 20-24px, semibold or bold
- Body: 14-16px, comfortable line-height
- Meta: 12-13px, secondary details

### What each role means

- Eyebrow: a small label above the title (for example: LIVE PROJECT, FEATURED, JUL 2026)
- Title: the main message of the card
- Body: short explanation text
- Meta: supporting details like date, read time, or status

## 2) Card Anatomy (Content Order)

Keep a predictable order inside cards, even when visual design differs.

1. Eyebrow (optional)
2. Title
3. Body text
4. Meta or extra info (optional)
5. Action row (optional)

## 3) Spacing Rhythm Inside Cards

Use a repeatable spacing rhythm so cards feel related.

- Card padding: 16px on mobile, 24px on desktop
- Eyebrow -> Title: 8px
- Title -> Body: 12px
- Body paragraph gap: 8px
- Body -> Footer/action: 16px

## 4) Text Density Rules

- Keep the first body paragraph short when possible
- If a block is long, split into bullets or a subheading
- Keep CTA text visually separate from body copy
- Use one clear idea per card title

## 5) Interactivity Rule

Interactivity is a behavior, not a visual tier.

- Visual tier controls prominence (base, raised, spotlight)
- Interactive modifier controls hover/focus behavior
- A card can be raised and interactive at the same time

## 6) Quick Example

- Eyebrow: LIVE PROJECT
- Title: BFshop
- Body: Take a look at BFshop as it is built.
- Meta: Updated 2 days ago
- Action: Open project
